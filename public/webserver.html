⚠️ Solusi 1: Apache XAMPP Gagal Start (Port 80 / 443 Bentrok)

🛑
Penyebab Umum: Di Windows 10/11, port 80 sering dipakai otomatis oleh World Wide Web Publishing Service (IIS), Skype, atau layanan Windows lain, sehingga Apache menampilkan pesan merah: Port 80 in use by "Unable to open process".

Cara Cepat Mengetahui Aplikasi Pemblokir:

Buka Command Prompt (cmd) sebagai Administrator, lalu jalankan perintah berikut:

Command Prompt (CMD) 
netstat -ano | findstr :80

Perhatikan angka PID di kolom paling kanan (misal 4812). Cek aplikasi pemilik PID tersebut dengan perintah:

Command Prompt (CMD) 
tasklist | findstr 4812

Solusi Paling Praktis (Matikan IIS yang Menyita Port 80):

Jalankan perintah ini sekali saja di CMD Administrator untuk menonaktifkan IIS bawaan Windows:

Command Prompt (CMD Administrator) 
net stop was /y
sc config was start= disabled
net stop w3svc /y
sc config w3svc start= disabled

Setelah perintah di atas dijalankan, klik tombol Start pada Apache di XAMPP Control Panel. Apache dijamin akan langsung berwarna hijau!

⚠️ Solusi 2: Error "VCRUNTIME140.dll" atau "MSVCR110.dll is missing"

💡
Penyebab: Versi PHP dan Apache dikompilasi menggunakan pustaka Microsoft Visual C++. Jika Windows Anda baru diinstal atau belum memiliki pustaka ini, server tidak bisa dijalankan sama sekali.

Langkah Penanganan 1-Klik:

LANGKAH 1
Buka subfolder 4. Developer Tools & Prasyarat Sistem di Google Drive.
LANGKAH 2
Unduh berkas Visual-C++-Redistributable-All-in-One.zip.
LANGKAH 3
Ekstrak file ZIP tersebut, klik kanan pada install_all.bat, lalu pilih Run as administrator.
LANGKAH 4
Skrip akan otomatis memasang seluruh paket Visual C++ dari versi 2005 hingga 2022 secara otomatis tanpa perlu restart komputer. Masalah DLL hilang selesai 100%!

🔒 Solusi 3: Menjalankan SSL HTTPS Lokal untuk PWA & HP

✨
Mengapa Butuh HTTPS di Localhost? Fitur Progressive Web App (PWA), Service Worker, Notifikasi Web, dan akses Kamera Web wajib berjalan di atas protokol HTTPS. Tanpa HTTPS yang valid, browser HP akan memblokir fitur-fitur tersebut.

Cara Mudah Membuat Sertifikat SSL Lokal Terpercaya:

1. Ekstrak mkcert-Local-SSL-Generator-x64.zip dari subfolder 4.
2. Buka CMD Administrator di folder tempat mkcert.exe berada, lalu ketik perintah berikut:

Command Prompt (CMD) 
mkcert -install
mkcert localhost 127.0.0.1 ::1 192.168.1.100

(Ganti 192.168.1.100 dengan alamat IP lokal komputer Anda).

Dua berkas sertifikat (localhost+3.pem dan localhost+3-key.pem) akan langsung tercipta dan siap dipasang ke konfigurasi Apache, Nginx, atau Laragon Anda. Browser Anda akan langsung menampilkan tanda gembok hijau aman tanpa peringatan merah!

🔄 Solusi 4: Cara Menambah / Ganti Versi PHP di XAMPP & Laragon

Jika Anda memiliki aplikasi yang membutuhkan versi PHP berbeda (misal ada proyek yang butuh PHP 7.4 dan proyek lain butuh PHP 8.2):

TIPS TERBAIK DI LARAGON
Di Laragon, ganti versi PHP sangat mudah: cukup unduh folder PHP yang diinginkan, letakkan di C:\laragon\bin\php\, lalu klik kanan ikon Laragon > PHP > Version > pilih versi yang diinginkan. Selesai dalam 3 detik!
DI XAMPP
Buka folder C:\xampp. Rename folder php saat ini menjadi php_82, lalu buat folder php baru dan masukkan isi folder versi PHP yang Anda inginkan. Buka file apache\conf\extra\httpd-xampp.conf untuk mencocokkan modul loader PHP-nya.

📦 Solusi 5: Mengatasi Error Upload Database Besar di phpMyAdmin

⚠️
Secara default, phpMyAdmin membatasi ukuran berkas upload hanya 2 MB atau 40 MB. Jika mengimpor file SQL di atas batas tersebut, akan muncul error "413 Request Entity Too Large" atau proses terhenti di tengah jalan.

2 Cara Mudah Mengatasinya:

Cara 1 (Paling Cepat & Direkomendasikan): Gunakan aplikasi HeidiSQL (ada di subfolder 3). Buka HeidiSQL, koneksikan ke port 3306 (user root, password kosong), klik menu Tools > Load SQL file... lalu klik Run. Berkas SQL ukuran 500 MB sekalipun akan selesai diimpor dalam hitungan detik tanpa batas limit browser!

Cara 2 (Lewat Terminal Command Line MySQL):

Command Prompt (CMD) 
cd C:\xampp\mysql\bin
mysql -u root -p nama_database < "D:\backup_database.sql"

Kumpulan perintah praktis yang sering digunakan saat mengoperasikan server lokal:

Memeriksa Port yang Sedang Digunakan 
netstat -ano | findstr :80
netstat -ano | findstr :3306

taskkill /F /PID <NOMOR_PID>
Memeriksa Versi Runtime yang Aktif 
php -v
node -v
python --version
java -version
Menghubungkan Localhost ke Internet dengan Ngrok 
ngrok http 80
